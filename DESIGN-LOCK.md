# DESIGN LOCK — APPROVED VISUAL MASTER

## Locked visual design
The current participant registration screen is the approved visual master.

Do NOT change:
- overall page composition
- mobile proportions
- top spacing / vertical position
- hero size and placement
- card width and placement
- typography scale
- input sizes
- button size and shape
- cream / deep-green visual palette
- border radius
- spacing rhythm
- responsive proportions

## Allowed future changes
Features may still be added or improved, including:
- registration fields and validation
- biometric logic
- QR / event pass functions
- offline storage and synchronization
- participant lookup
- check-in logic
- snack / lunch / raffle claiming
- master database tools
- reports
- security
- new functional pages
- backend / database integrations

## Rule for new UI
Any new feature that needs visible controls must match the approved visual master. Do not redesign the existing screen to accommodate new features. Add functionality without changing the locked visual identity.

Approved master: current participant registration design.
