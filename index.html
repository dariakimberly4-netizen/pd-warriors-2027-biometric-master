Important Deployment Note

This GitHub Pages version is a functional workflow prototype using local browser storage. True automatic phone-to-phone Nearby Connections sync and production biometric credential verification require a native Android app (or a trusted local server) because ordinary GitHub Pages cannot access Android Nearby Connections directly.
